The GitHub integration links pull requests and commits to Fernway tasks. It is available on the Team and Business plans. An Admin installs the Fernway GitHub app under Settings, then Integrations, then GitHub, and chooses which repositories it can read.

Mention a task key such as FW-123 in a pull request title, description or commit message to link it. The task then shows the pull request with its status: open, merged or closed.

Write Fixes FW-123 or Closes FW-123 in the pull request description to complete the task automatically when the pull request is merged into the default branch.
