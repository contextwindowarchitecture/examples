Create a task by pressing N anywhere in a project, or with the plus button at the bottom of a column. A task has a title, an optional description in Markdown, one assignee, a due date, labels and attachments.

Subtasks break a task into steps. Add them from the task's Subtasks section; each subtask can have its own assignee and due date. A task shows a progress bar of completed subtasks, and completing the task does not complete its open subtasks.

Dependencies mark a task as blocked by another. Choose Add dependency in the task menu and pick the blocking task, which can be in any project in the workspace. A blocked task shows a lock icon until every blocking task is complete.

Each task gets a short key such as FW-123, made from the project prefix and a number. Use the key to link a task from comments, from other tasks, or from a GitHub pull request.
